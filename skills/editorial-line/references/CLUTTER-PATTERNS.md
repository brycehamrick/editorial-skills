# Clutter Patterns Reference

Zinsser's taxonomy of clutter from *On Writing Well*. Use this during the Clutter Sweep (Framework 1) to identify specific pattern types when writing L# issues.

---

## Category 1: Unnecessary Qualifiers

Words that weaken the assertion they modify. Almost always cut.

| Clutter word | What to do |
|---|---|
| very | Cut. If the assertion weakens, strengthen the assertion. |
| quite | Cut. |
| rather | Cut. |
| somewhat | Cut. |
| pretty (as in "pretty good") | Cut. |
| little (as in "a little unclear") | Cut. |
| sort of | Cut. |
| kind of | Cut. |
| fairly | Cut. |
| slightly | Cut unless the slight degree is the actual point. |
| largely | Cut unless scope is the actual point. |
| generally | Cut unless the exception matters; if it does, name it. |

**Pattern note:** Qualifiers cluster around claims the writer is uncertain about. If a sentence needs three qualifiers to feel accurate, the sentence is probably trying to cover too much territory.

---

## Category 2: Bureaucratic Constructions

Institutional language that replaces simple words with weighted phrases. Substitute the direct word.

| Clutter phrase | Direct substitute |
|---|---|
| at this point in time | now |
| at the present time | now |
| due to the fact that | because |
| in light of the fact that | because |
| owing to the fact that | because |
| in the event that | if |
| in order to | to |
| with regard to | about |
| with respect to | about |
| in terms of | about / for / in (choose one) |
| on the basis of | by / because of |
| for the purpose of | to |
| in the process of | (cut; restructure the verb) |
| in the nature of | like |
| prior to | before |
| subsequent to | after |
| in close proximity to | near |
| at this juncture | now / here |
| it is our intention to | we intend to / we will |
| it is our recommendation that | we recommend |
| it is our belief that | we believe |
| it is important to note that | (cut; lead with the note) |
| it should be pointed out that | (cut; point it out) |
| it is worth mentioning that | (cut; mention it) |
| it is interesting to note that | (cut; note it, and trust the reader to find it interesting) |
| needless to say | (cut; if needless, don't say it) |
| as a matter of fact | (cut; state the fact) |
| for all intents and purposes | (cut; state what is actually intended and purposed) |

## Category 3: Redundant Pairs

Two words where one does the full work of both.

| Redundant pair | Keep one |
|---|---|
| each and every | each / every |
| first and foremost | first |
| true and accurate | true / accurate |
| various and sundry | various |
| null and void | void |
| cease and desist | stop |
| full and complete | complete |
| final and conclusive | conclusive |
| free and clear | free |
| new and novel | new |
| past history | history |
| future plans | plans |
| advance planning | planning |
| end result | result |
| final outcome | outcome |
| unexpected surprise | surprise |

## Category 5: Throat-Clearing Openers

Sentence introductions that defer the content. Cut the opener and start with the substance.

| Throat-clearing opener | Replace with |
|---|---|
| It is interesting to note that X | X |
| It should be pointed out that X | X |
| It is worth noting that X | X |
| It is important to remember that X | X |
| What I am trying to say is X | X |
| The point I am making is X | X |
| As I mentioned previously, X | X |
| As we have seen, X | X |
| As noted above, X | X |
| Clearly, X | X (if it's clear, you don't need to say so) |
| Obviously, X | X (if it's obvious, you don't need to say so) |
| Needless to say, X | (Don't say it if it's needless; if it needs saying, say it plainly) |

## Category 6: Zombie Nouns (Nominalizations)

Verbs that have been turned into nouns and propped up by weak verbs. Return them to verb form.

| Nominalized form | Restored verb form |
|---|---|
| make an assessment of | assess |
| conduct an investigation of | investigate |
| have a discussion about | discuss |
| reach a conclusion | conclude |
| give consideration to | consider |
| provide assistance to | assist |
| make a decision | decide |
| place emphasis on | emphasize |
| show improvement | improve |
| demonstrate an understanding of | understand |
| make a recommendation | recommend |
| take action on | act on |
| make a contribution to | contribute to |
| provide a description of | describe |
| be in agreement | agree |
| be in violation of | violate |
| be of the opinion that | believe / think |
| have knowledge of | know |
| have a tendency to | tend to |

**Diagnostic:** Search for "make a," "have a," "provide a," "give a," "conduct a," and "perform a." These constructions almost always contain a buried verb.

## Category 7: The "That" Problem

"That" is often deletable. Read the sentence without it. If the meaning is preserved, cut it.

**Often deletable:**
- "I believe that this approach is correct." → "I believe this approach is correct."
- "She argued that the data was incomplete." → "She argued the data was incomplete."
- "He knew that it was time." → "He knew it was time."

**Not deletable (when "that" introduces a clause that would otherwise be misread):**
- "I realized that the problem wasn't the data." (Cutting "that" can create a momentary misread: "I realized the problem" — then the reader has to backtrack.)
- Sentences where the subject of the subordinate clause could initially be read as the object of the main verb.

**Test:** Read without "that." If the sentence parses cleanly on first read, cut it. If there's any risk of misread, keep it.

---

## Category 8: Hedge Phrases

Phrases that signal the writer doesn't fully trust the sentence. Either commit to the claim or cut it.

| Hedge phrase | The problem |
|---|---|
| in a manner of speaking | Signals the expression isn't quite accurate. Either find an accurate expression or drop the claim. |
| as it were | Same as above. |
| to a certain extent | How much? If it matters, say so. If it doesn't, drop the hedge. |
| in some ways | Which ways? Name them. |
| more or less | How much? Imprecision is acceptable when precision is genuinely impossible; otherwise it is avoidance. |
| one could argue that | Either argue it or don't. This construction creates distance the writer rarely intends. |
| it could be said that | Same as above. |
| some might say | Who? If citing an actual position, attribute it. If not, drop it. |
| arguably | Use sparingly. "Arguably the best" is almost always weaker than making the case. |

## Pattern Clusters: What They Signal

When clutter patterns appear in clusters, they often signal something beyond word choice:

| Pattern cluster | What it often signals |
|---|---|
| Heavy nominalization + bureaucratic constructions | Writer is in institutional register; hasn't made the transition to reader-facing prose |
| Excessive hedging + "one could argue" constructions | Uncertainty about the claim itself, not just the phrasing |
| Throat-clearing openers + "as we have seen" | Writer is recapping for themselves, not advancing for the reader |
| Redundant qualifiers + redundant pairs | Draft hasn't been cut; writer is in accumulation mode |
| Heavy use of "there is/are" + "it is" | Writer is not tracking where the real subject of each sentence is |

When a pattern cluster appears, name it in the L# issue. "Nominalization accumulation in paragraph 4" is more useful than six separate issues for the same pattern.
