# Five-Pass Proof Checklist

Use this as a running tally during each pass. Mark each item complete (✓), flagged (F), or not applicable (—) for the document being proofed.

---

## Pass 1: Global Formatting Scan
*Do not read words. Read geometry.*

| Item | Status | Notes |
|---|---|---|
| Page numbers sequential, no skips or repeats | | |
| Running headers correct for each page | | |
| Running footers correct and consistent | | |
| Level 1 headings: identical font, size, weight, spacing | | |
| Level 2 headings: identical to each other | | |
| Level 3 headings (if present): identical to each other | | |
| No heading levels skipped | | |
| Body text paragraph spacing uniform | | |
| Space before/after headings consistent | | |
| Widows flagged (single word/short line at top of page) | | |
| Orphans flagged (first line stranded at bottom of page) | | |
| Stranded headings flagged (heading at page bottom with < 2 lines following) | | |
| Pull quotes and callouts aligned correctly | | |
| Images not stretched, cropped incorrectly, or pixelated | | |

| Item | Status | Notes |

| Item | Status | Notes |
|---|---|---|

| Missing small words checked (a, the, in, of, to) | | |

| Opening parentheses all have closing parentheses | | |
| Paired em dashes both present | | |
| Smart quotes consistent throughout (no mix of smart/straight) | | |
| Em dashes not converted to hyphens by layout process | | |
| En dashes used correctly for ranges (not hyphens) | | |
| All proper nouns verified against Style Sheet | | |

## Second Proof Recommendation

After corrections are applied, run a targeted second proof:
- Re-check every area where a correction was made (new errors are most likely at correction sites)
- Re-run Pass 2 (High-Risk) on any headings that were corrected
- Re-run Pass 5 (Sense) on any passages where meaning-level corrections were made
- Verify that no correction introduced a new orphan, widow, or stranded heading
