    **Section 6: Workflow**
    Eight steps adapted from RESEARCH.md code example. Single linear workflow (not three-mode branching):

    Step 1: Load Preferences (check EXTEND.md, merge glossaries -- CLI overrides EXTEND.md)
    Step 2: Read Context (read `.agents/editorial-context.md` if exists, load audience/voice/style. Do not ask for what's already there. Do not write to it.)
    Step 3: Materialize Source and Create Output Directory
      - File: use as-is
      - Inline text: save to `translate/{slug}.md`
      - URL: fetch content, save to `translate/{slug}.md`
      - Output dir: `{source-dir}/{source-basename}-{target-lang}/`
      - Conflict: rename existing to `{name}.backup-YYYYMMDD-HHMMSS/`
    Step 4: Assess Content Length
      - Estimate word count
      - Below chunk threshold: translate as single unit
      - At or above: chunked translation (Step 4.1)
    Step 4.1: Long Content Preparation (chunked only)
      - Extract terminology from full document
      - Build session glossary (merge extracted + EXTEND.md + --glossary)
      - Split: `${BUN_X} {baseDir}/scripts/main.ts <file> [--max-words <chunk_max_words>] [--output-dir <output-dir>]`
      - Save chunks to output-dir/chunks/
    Step 5: Analyze
      - Full content analysis per [references/ANALYSIS-WORKFLOW.md](references/ANALYSIS-WORKFLOW.md) Step 1
      - Save to `{output-dir}/01-analysis.md`
    Step 6: Assemble Translation Prompt
      - Read 01-analysis.md, inline style preset, content background, merged glossary, comprehension challenges
      - Save to `{output-dir}/02-prompt.md`
      - Template in [references/ANALYSIS-WORKFLOW.md](references/ANALYSIS-WORKFLOW.md) Step 2
    Step 7: Translate
      - If Agent tool available and chunked: spawn one subagent per chunk in parallel, each reads 02-prompt.md, translates its chunk -> chunk-NN-draft.md. Merge in order, prepend frontmatter.md if exists -> translation.md
      - If not chunked or Agent unavailable: translate source following 02-prompt.md -> translation.md
      - Invoke `stop-slop` when drafting translated prose if available (per CLAUDE.md convention for Phase 2 prose)
    Step 8: Output Summary
      - Display: Source, Languages (from -> to), Output dir, Final file path, Glossary terms applied
      - Image-language pass: check referenced images for source-language text, remind user if found
